# Get a Job!

This is a game that we developed using the Phaser 4 engine and hosted in a Next.js web application.
The latest production version is already hosted on a public server via Vercel, so you can just click
the link in the about section to start playing!

## Story

We're in a rough economy and it's been hard to hold a job down in these times. You had just decided 
to move out too. Too bad you already told Mom that you've been hard at work these past few months 
and she's coming to visit...**TONIGHT?!** *You need to get a job, ASAP!*

## Features

We tried to incorporate some elements of inspirational arcade games into this project:

### 2D Viewpoint

Get a Job! is a top-down 2D adventure game with a scrolling camera view. We tried to recreate a 
side-scrolling feel close to the classic Pokemon and The Legend of Zelda games. The scenes in the 
game are rendered as layers of tiles, and the player can move in each of the 4 main directions.

### Pixel Art

Arcade-style graphics provide a lot of character to each of the scenes in the game. We're not great 
artists, so most of the concept design and sprites were created with the help of generative AI, and 
the tile textures are the work of the incredible community of graphic designers at Itch.io. They are 
truly the pixel art pros and have contributed so much to make free indie games like this one possible.

### Mini-levels

While we were tempted to dive into a longer story-based campaign, we ultimately decided to section the 
playable parts of the game into small levels with their own style of play. This not only adds variety 
to the game but also lets us showcase different game genres that work well with the arcade theme. 
Maybe you can guess which famous games inspired these levels!

### Web interface

Although this isn't a classic arcade feature, we chose to release the game online to make it as 
accessible as possible. One of the nice things about arcade games is that they are quick and have 
little barrier to entry, and there's really no easier way to start up a game than to click a link 
and have it already loaded on your browser. Some clever engineers have done this with online 
emulators. This project isn't quite that awesome, but we did keep the awesome idea of getting 
our own website for it!
